# Physical AI & Humanoid Robotics Textbook

This is the source code for the Physical AI & Humanoid Robotics textbook built with Docusaurus.

## Installation

```bash
npm install
```

## Local Development

```bash
npm start
```

This command starts a local development server and opens up a browser window. Most changes are reflected live without having to restart the server.

## Build

```bash
npm run build
```

This command generates static content into the `build` directory and can be served using any static contents hosting service.

## Deployment

The site is set up to be deployed to GitHub Pages. Using GitHub Actions, the site will be automatically built and deployed when changes are pushed to the main branch.
